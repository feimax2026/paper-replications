# Kanamura and Bunn (2022) replication

This project starts a transparent, public-data replication of:

Kanamura, T. and Bunn, D. W. (2022). *Market making and electricity price formation in Japan*. Energy Economics, 107, 105765.

[Read the notebook on GitHub](https://github.com/feimax2026/paper-replications/blob/main/replications/kanamura-bunn-2022-jepx/notebooks/01_descriptive_replication.ipynb) · [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/feimax2026/paper-replications/blob/main/replications/kanamura-bunn-2022-jepx/notebooks/01_descriptive_replication.ipynb)

## Data

- `data/raw/jepx_spot.csv`: JEPX day-ahead market data, including system price and buy/sell bid volumes.
- `data/raw/japan_weather.csv`: daily maximum and minimum temperature data for Japan's major cities.
- `data/processed/kanamura_bunn_2022_panel.csv`: analysis panel generated from the two raw files.

The raw files are downloaded from the Japanese Electricity Market Data Hub, which identifies JEPX and the Japan Meteorological Agency as its upstream sources. Before a final replication, replace these convenience copies with the corresponding official downloads and record their download dates.

## First-stage design

The paper's displayed sample spans FY2015 to FY2019. We retain observations from 2015-04-01 through 2020-03-08, compute scarcity as buy bid volume minus sell bid volume, and assign each observation its Japanese fiscal year.

The paper uses Tokyo temperature as a first-order approximation for the national JEPX system price. The downloaded weather file supplies daily maximum and minimum temperature, so the first panel uses their midpoint as `tokyo_temperature_proxy_c`. This is a documented approximation, not a claim of exact input-level replication.

## Run


The next milestone is to reproduce the paper's descriptive time-series figures and its temperature-scarcity scatter plots before estimating the state-switching model.

Run the descriptive stage with:

```sh
python3 scripts/descriptive_analysis.py
```

It produces fiscal-year statistics under `report/` and two SVG figures under `figures/`.

## Read and verify

The processed panel is suitable for version control. The raw source files are deliberately ignored by Git because they can be regenerated by `scripts/download_data.py`.
