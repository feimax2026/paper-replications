# Paper Replications

An evidence-first collection of paper replications. Each project keeps the
paper's question, public-data pathway, executable analysis, generated figures,
and a concise statement of what was and was not reproduced.

## Projects

| Project | Paper | Status |
| --- | --- | --- |
| [Kanamura and Bunn (2022): JEPX market making](replications/kanamura-bunn-2022-jepx/) | *Market making and electricity price formation in Japan* | Descriptive replication complete |

## Project convention

Each directory under `replications/` is self-contained:

```text
replications/<paper-slug>/
  README.md
  notebooks/
  scripts/
  data/processed/
  figures/
  report/
```

Large raw downloads are excluded from version control and regenerated by the
project's download script. Processed analysis panels, generated figures, and
reports are committed so that a reader can inspect the result immediately.
